# cpu-language-model

Train language models with CPUs alone. The aim is to learn how far CPU-only training can go, and to look for methods that let it compete with GPU training.

## The frame (fixed; only the user changes it)

- **CPU only:** no GPU, for anything.
- **Machine:** a VPS rented for this project. Every rental needs the user's approval. Never run training or other heavy work on the machine you run on.
- The data, the evaluation and the budget per run are decided with the user before the first run.
